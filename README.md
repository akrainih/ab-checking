# A/B-тестирование новой функции

## Описание проекта

В рамках проекта проведён анализ результатов A/B-тестирования новой функции. Цель — оценить, влияет ли её внедрение на удержание пользователей и выполнение домашних заданий.

Пользователи были разделены на две группы:
- **Группа A** — контрольная группа.
- **Группа B** — тестовая группа, использовавшая новую функцию.

## Цель исследования

Определить, оказывает ли новая функция положительное влияние на пользовательскую активность и ключевые продуктовые метрики.

### Исследуемые метрики

- **Retention D7** — доля пользователей, вернувшихся на 7-й день.
- **Retention D14** — доля пользователей, вернувшихся на 14-й день.
- **Completion Rate** — доля пользователей, завершивших домашнее задание среди начавших его.

## Данные

Для анализа использовались два набора данных:

- `groups` — информация о пользователях, принадлежности к экспериментальной группе, дате регистрации и классе.
- `events` — журнал пользовательских событий с временными метками и типами событий.

## Этапы анализа

1. **Предварительная обработка данных**
   - Проверка пропусков и дубликатов.
   - Проверка корректности распределения пользователей по группам.
   - Обработка конфликтующих записей.
   - Выявление и исключение аномальных пользователей с экстремальной активностью.

2. **Исследовательский анализ данных (EDA)**
   - Анализ распределения пользователей по группам.
   - Изучение пользовательской активности.
   - Анализ распределения событий.

3. **Расчёт продуктовых метрик**
   - Расчёт Retention D7 и D14.
   - Построение воронки выполнения домашних заданий.
   - Расчёт Completion Rate.

4. **Статистический анализ**
   - Проверка статистической значимости различий между группами.
   - Расчёт доверительного интервала для разницы Completion Rate.

## Результаты

| Метрика | Группа A | Группа B | Разница B − A |
|---|---:|---:|---:|
| Retention D7 | 72,69% | 77,98% | +5,29 п.п. |
| Retention D14 | 28,81% | 36,24% | +7,43 п.п. |
| Completion Rate | 97,63% | 98,83% | +1,20 п.п. |

Все три различия статистически значимы при уровне значимости 5%:

| Метрика | P-value |
|---|---:|
| Retention D7 | 0,00000213 |
| Retention D14 | 8,44 × 10⁻¹⁰ |
| Completion Rate | 0,000430 |

## Бизнес-вывод

Тестовая группа B показала улучшение по всем исследуемым метрикам. Результаты позволяют предположить, что новая функция положительно влияет на удержание пользователей и выполнение домашних заданий.

При этом сегментный анализ не проводился из-за недостатка доступных данных. Поэтому пока нельзя утверждать, что эффект одинаково проявляется во всех категориях пользователей. Возможно, основную часть положительного результата обеспечивает отдельный сегмент.
